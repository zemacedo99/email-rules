rwz-importer

Outlook rules for New Outlook / OWA no token

What this is

Manage your New Outlook / Outlook-on-the-web inbox rules: review and edit them, run them over the mail already in your inbox, get rule suggestions from your recent mail, and import an Outlook Classic .rwz export.

Connecting your mailbox

Two ways — pick one in Setup below:

  1. Sign in with Microsoft (easiest). Click the Sign in with Microsoft button, open the page it shows, type the short code, and finish signing in as usual. The token is captured automatically — no DevTools, no copy/paste.
  2. Paste a token manually. Use this if your organisation blocks the button above (some do). Setup has a one-click console snippet that grabs the token from a tab you're already signed in to — no Network-tab hunting.

Either way, the token is held in this server's memory only — never written to disk, never shown back here, never sent anywhere but Microsoft. It expires after about an hour; just sign in again.

Safe by default. Running rules over your inbox always shows a preview with a match count first — no mail moves until you confirm. Creating or editing a rule makes it active for future mail server-side; the Run button is what files the existing backlog. Deleting a rule asks for confirmation. Cross-mailbox addresses are flagged, never rewritten silently.

Paste a token manually (use this if sign-in is blocked)

If Sign in with Microsoft is blocked by your organisation, grab the token from a browser tab that's already signed in to Outlook — that session is allowed, so this always works:

  1. Open https://outlook.office.com and let your mailbox finish loading.
  2. Press F12 → Console tab.
  3. , paste it at the console prompt, and press Enter. It finds your Outlook token and copies it to the clipboard. (If the console warns about pasting, type allow pasting first.)
  4. Come back here, paste it below, and click Save.

Rule suggestions

    
Scans recent message metadata (sender, subject, date — never bodies)
      and proposes rules for traffic nothing currently files: high-volume senders, domain
      clusters, and recurring [tags] in subjects.

    

      

      

      

      

    

    

      
      
    

    

  


  
  

    
Import a .rwz export

    
Parse an Outlook Classic .rwz file (offline), review the rules,
      then plan and apply them. Apply always shows a plan and requires a confirmation token —
      nothing is written until you click Apply on a fresh plan.
