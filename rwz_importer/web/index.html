What this is

Manage your server-side inbox rules — on Outlook/Exchange or Gmail: review and edit them, run them over the mail already in your inbox, get rule suggestions from your recent mail, and import an Outlook Classic .rwz export.

Connecting your account

Choose your provider and connect in the Connect your account panel below. Outlook offers one-click sign-in; either provider also accepts a pasted access token.

The token is held in this server's memory only — never written to disk, never shown back here. It is short-lived (about an hour); just connect again when it expires.

Safe by default. Running rules over your inbox always shows a preview with a match count first — no mail moves until you confirm. Creating or editing a rule makes it active for future mail server-side; the Run button is what files the existing backlog. Deleting a rule asks for confirmation. How do I get a client ID & secret? →
  1. Open the Google Cloud Console ↗ and create (or pick) a project.
  2. APIs & Services → Library → search Gmail API → Enable.
  3. OAuth consent screen → User type External → add your own address under Test users.
  4. Credentials → Create credentials → OAuth client ID → Application type Desktop app.
  5. Copy the Client ID and Client secret it shows into the fields below.

Or set them once via the GOOGLE_OAUTH_CLIENT_ID / GOOGLE_OAUTH_CLIENT_SECRET environment variables and they'll be pre-filled here.
